# javascript-exercises

Repositório dedicado ao armazenamento de exercícios de lógica de programação e algoritmos resolvidos em **JavaScript**.

## Organização

Os exercícios são separados em diferentes pastas. Atualmente existe apenas a pasta da plataforma LeetCode, mas serão adicionadas mais pastas e exercícios em breve.

### Plataformas incluídas
* [LeetCode](https://leetcode.com)


## Como executar
Para rodar os exercícios na sua máquina, certifique-se de ter o [Node.js](https://nodejs.org) instalado e siga os passos abaixo:

1. Clone o repositório:
   ```bash
   git clone https://github.com/ryanwlvp/javascript-exercises.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd javascript-exercises
   ```

3. Execute o arquivo desejado passando o seu caminho:
   ```bash
   node leetcode/exercises/easy/1-two-sums.js
   ```
